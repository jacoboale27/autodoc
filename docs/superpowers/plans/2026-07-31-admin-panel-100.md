# Panel de Administración al 100% — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Llevar el Panel de Administración de AutoDoc del 96.5% al 100%: gráficos globales de crecimiento en el dashboard, moderación/baneo de cuentas, exportación real de datos a CSV/Excel, y filtros avanzados de talleres por municipio/departamento/especialidad.

**Architecture:** Se extiende la arquitectura existente (Clean Architecture + Provider). El dashboard ya usa `AdminDashboardProvider` + `AdminService.watchDashboardMetrics()` con streams en tiempo real sobre Firestore — se añaden streams nuevos agregados por mes. La moderación reutiliza el campo `estado` (String) que YA funciona como mecanismo de baneo/suspensión en `usuarios` y `talleres`; no se introduce un campo `isActive:boolean` paralelo para evitar duplicar la lógica de moderación existente. La exportación pasa de "copiar al portapapeles" a generar un archivo `.csv` real descargable usando el paquete `csv` + descarga condicional (web vs. mobile). Los filtros avanzados se añaden en `AdminTalleresScreen` sobre datos ya cargados en memoria (`AdminProvider.talleres`), sin cambiar las queries de Firestore.

**Tech Stack:** Flutter, Provider, Cloud Firestore, `fl_chart` (ya en pubspec), paquete nuevo `csv: ^6.0.0`, `package:web` (ya en pubspec, para descarga en navegador).

## Global Constraints

- Campos Firestore en snake_case español (`fecha_registro`, `ubicacion_municipio`), modelos Dart en camelCase con `fromMap`/`toMap` manuales (sin `json_serializable`).
- Métodos y nombres de clases en español, siguiendo el código existente (`aprobarUsuario`, `suspenderUsuario`).
- Providers: patrón `_setLoading(true) → try/catch → _setError(e.toString()) → finally _setLoading(false)`, siempre terminan en `notifyListeners()`.
- Toda acción administrativa de moderación DEBE registrar un log vía `AdminService._logAction(adminUid, accion, modulo, referenciaId, detalle)` → colección `admin_logs`, para aparecer en `admin_logs_screen.dart`.
- UI: usar `Responsive.padding/fontSize/iconSize(context, n)` en vez de valores fijos; `context.l10n.xxx` para strings (localización ARB en `lib/l10n/`).
- No introducir `isActive:boolean`. Reutilizar el campo `estado` (`'activo'|'suspendido'|'pendiente'|'aprobado'|'rechazado'`) ya presente en `UserModel` y `WorkshopModel`.
- Cualquier ruta nueva bajo `/admin/...` debe añadirse al `Set<String> _adminRoutes` en `lib/core/router/app_router.dart` o quedará sin protección de rol.
- `firestore.rules`: el campo `estado` en `usuarios` ya está excluido de lo que el propio dueño puede modificar (solo admin) — no tocar esa regla, solo verificar que se mantenga tras cualquier cambio de reglas de `talleres`.

```dart
final seisMesesAtras = DateTime(now.year, now.month - 5, 1);
final usuariosSnap = await _firestore
    .collection(FirestoreCollections.usuarios)
    .where('fecha_registro', isGreaterThanOrEqualTo: Timestamp.fromDate(seisMesesAtras))
    .get();
final usuariosPorMes = <String, int>{};
for (final doc in usuariosSnap.docs) {
  final fecha = (doc.data()['fecha_registro'] as Timestamp?)?.toDate();
  if (fecha == null) continue;
  final key = '${fecha.year}-${fecha.month.toString().padLeft(2, '0')}';
  usuariosPorMes[key] = (usuariosPorMes[key] ?? 0) + 1;
}

// talleresPorMes: mismo cálculo pero filtrando rol Taller/Mecánico
final talleresPorMes = <String, int>{};
for (final doc in usuariosSnap.docs) {
  final data = doc.data();
  final rol = (data['rol'] as String?)?.toLowerCase() ?? '';
  if (!rol.contains('taller') && !rol.contains('mecanico') && !rol.contains('mecánico')) continue;
  final fecha = (data['fecha_registro'] as Timestamp?)?.toDate();
  if (fecha == null) continue;
  final key = '${fecha.year}-${fecha.month.toString().padLeft(2, '0')}';
  talleresPorMes[key] = (talleresPorMes[key] ?? 0) + 1;
}
```

```dart
// lib/features/admin/presentation/widgets/user_growth_chart.dart
import 'package:fl_chart/fl_chart.dart';
import 'package:flutter/material.dart';
import 'package:autodoc/core/theme/app_colors.dart';
import 'package:autodoc/core/widgets/app_card.dart';
import 'package:autodoc/core/utils/l10n_extension.dart';

class UserGrowthChart extends StatelessWidget {
  final Map<String, int> dataPorMes;

  const UserGrowthChart({super.key, required this.dataPorMes});

  @override
  Widget build(BuildContext context) {
    final entries = dataPorMes.entries.toList()..sort((a, b) => a.key.compareTo(b.key));
    final spots = <FlSpot>[
      for (var i = 0; i < entries.length; i++) FlSpot(i.toDouble(), entries[i].value.toDouble()),
    ];

    return AppCard(
      child: Padding(
        padding: const EdgeInsets.all(16),
        child: Column(
          crossAxisAlignment: CrossAxisAlignment.start,
          children: [
            Text(context.l10n.crecimientoUsuarios, style: Theme.of(context).textTheme.titleMedium),
            const SizedBox(height: 16),
            SizedBox(
              height: 200,
              child: entries.isEmpty
                  ? Center(child: Text(context.l10n.sinDatos))
                  : LineChart(
                      LineChartData(
                        lineBarsData: [
                          LineChartBarData(
                            spots: spots,
                            isCurved: true,
                            color: AppColors.primary,
                            barWidth: 3,
                            dotData: const FlDotData(show: true),
                          ),
                        ],
                        titlesData: FlTitlesData(
                          bottomTitles: AxisTitles(
                            sideTitles: SideTitles(
                              showTitles: true,
                              getTitlesWidget: (value, meta) {
                                final idx = value.toInt();
                                if (idx < 0 || idx >= entries.length) return const SizedBox.shrink();
                                return Text(entries[idx].key.substring(5), style: const TextStyle(fontSize: 10));
                              },
                            ),
                          ),
                        ),
                      ),
                    ),
            ),
          ],
        ),
      ),
    );
  }
}
```

Nota: si `context.l10n.crecimientoUsuarios`/`sinDatos` no existen aún en el ARB, añádelos a `lib/l10n/app_es.arb` (y al `app_en.arb` equivalente si el proyecto soporta inglés) con textos `"Crecimiento de usuarios"` / `"Sin datos"`, y corre `flutter gen-l10n` antes de compilar.

```dart
// lib/core/utils/csv_export_util_web.dart
import 'dart:convert';
import 'package:web/web.dart' as web;

Future<void> downloadCsv(String filename, String csvContent) async {
  final bytes = utf8.encode('﻿$csvContent'); // BOM para que Excel detecte UTF-8
  final blob = web.Blob([bytes.toJS].toJS, web.BlobPropertyBag(type: 'text/csv;charset=utf-8'));
  final url = web.URL.createObjectURL(blob);
  final anchor = web.document.createElement('a') as web.HTMLAnchorElement
    ..href = url
    ..download = filename;
  web.document.body!.appendChild(anchor);
  anchor.click();
  web.document.body!.removeChild(anchor);
  web.URL.revokeObjectURL(url);
}
```

Nota: verifica la API exacta de `package:web` instalada (`web: ^1.1.1`) contra `pub deps` — la conversión `bytes.toJS`/`[...].toJS` requiere `dart:js_interop`; si la versión instalada difiere en la API de `Blob`, ajusta usando la documentación de `package:web` para esa versión exacta antes de dar el paso por completo.
