# AutoDoc v1.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement the v1.1 package which includes Google Sign-In, FCM Push Notifications, Offline Chat caching via Hive, Multilingual support, and PDF support for invoices.

**Architecture:** We are augmenting existing providers (`AuthProvider`, `ChatProvider`) and setting up global services (`PushNotificationService`) while adhering to the established clean architecture.

**Tech Stack:** Flutter, Firebase Auth, Google Sign In, Firebase Cloud Messaging, Hive, AppLocalizations, File Picker.

## Global Constraints

- Do not upload `.env` or commit secrets.
- All new features must have unit tests verifying logic.
- Run `dart format`, `flutter analyze`, and `flutter test` after each task.
